# Day 15 – DNS Security Basics

**Intern:** Ritu Raj | **Domain:** Cyber Security | **Veda Technology**

## Objective
Understand DNS from a security perspective.

## Approach
- Studied how DNS resolution works (resolver → root → TLD → authoritative server)
- Identified common DNS threats: spoofing, cache poisoning, hijacking, tunneling, DDoS
- Learned defenses: DNSSEC, DoH/DoT, registrar lock, monitoring
- Documented findings in a DNS security report

## Tools Used
Browser, Google Docs

## Outcome
Completed a DNS security report covering DNS basics, the resolution flow, attack types, DNSSEC, and prevention best practices.

## Files
- `DNS_Security_Report.pdf`

## Key Takeaways
DNS lacks built-in authentication, which makes attacks like spoofing possible. DNSSEC and encrypted DNS (DoH/DoT) greatly reduce the risk.
